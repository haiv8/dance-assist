# EXE packaging and size reduction

## 1) Run from source
- `run-desktop.bat`: desktop mode only. It requires an embedded window and exits with an error if desktop dependencies are missing.
- `run-browser-debug.bat`: browser debug mode. It keeps the browser-based flow for frontend debugging.
- Both modes start backend on `127.0.0.1:8000` and serve frontend dist on `127.0.0.1:4173`.
- Runtime data defaults to `%LOCALAPPDATA%\\dance-assist` (or `.runtime` if LOCALAPPDATA is unavailable).

## 2) Desktop dependencies
- Embedded desktop mode currently needs `pywebview` in `.venv`.
- On Windows, install `pythonnet` as well to make the native embedded window backend available more reliably.

## 3) Build EXE
1. Install backend dependencies in `.venv`.
2. Build frontend once:
   - `cd frontend`
   - `npm ci`
   - `npm run build`
3. Run:
   - `powershell -ExecutionPolicy Bypass -File scripts/build-desktop-exe.ps1`
4. Output EXE:
   - `dist-desktop/dance-assist/dance-assist.exe`
5. The build script ensures `pyinstaller`, `pywebview`, and `pythonnet` are available before packaging.

## 4) Runtime architecture change
- Dynamic folders moved to runtime home:
  - `uploads/`
  - `data/`
  - `models/`
  - `outputs/`
- Backend reads and writes from `DANCE_ASSIST_HOME`.
- First run can migrate legacy uploads from `backend/uploads`.
- Optional retention: `DANCE_ASSIST_RETAIN_OUTPUT_PAIRS` (desktop default is `30`).

## 5) Why project size became huge
Main reasons in this repository:
- historical `outputs/` contained very large zip artifacts
- `.git/objects` keeps large historical blobs
- `.venv/` and `frontend/node_modules/` are dependency caches

## 6) Size audit
- `powershell -ExecutionPolicy Bypass -File scripts/size-audit.ps1`

## 7) Safe cleanup
Dry run:
- `powershell -ExecutionPolicy Bypass -File scripts/cleanup-project-size.ps1 -DryRun`

Actual cleanup (default cleans output zips + pycache + frontend cache):
- `powershell -ExecutionPolicy Bypass -File scripts/cleanup-project-size.ps1`

Optional git object compaction:
- `powershell -ExecutionPolicy Bypass -File scripts/cleanup-project-size.ps1 -RunGitGc`
